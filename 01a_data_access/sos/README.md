# Request SOS Data for download
The Sublimation of Snow (SOS) dataset is provided courtesy of the NSF NCAR EOL team. Follow these steps to access the data:
1. Go to [SOS: ISFS Surface Meteorology and Flux Products](https://data.eol.ucar.edu/dataset/633.001)
2. Scroll to `Data access` and click `ORDER`
3. Select `sos_isfs_qc_geo_tiltcor_5min_v20241227.tar.gz (232 MB)`. Other options can be downloaded but the data used in this analysis come from this dataset. 
4. Provide email and affilication
5. Click `Continue` and wait for email containing your dataset.
6. Untar and save your dataset to the appropriate directory. 

*Note*: Other datasets can be requested from the main project data storage site [here](https://data.eol.ucar.edu/master_lists/generated/sos/).
